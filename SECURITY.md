# Security and Responsible Use

This repository is intended for defensive security, education, OSINT research, and authorized assessment.

## Rules of use

Use Shodan data and the examples in this repository only for:

- Assets you own or administer.
- Environments for which you have explicit authorization.
- Defensive attack-surface management.
- Research that does not involve unauthorized access or disruption.

Publicly indexed information is not permission to authenticate to, modify, exploit, disrupt, or otherwise interact with a third-party system.

## Reporting exposed systems

If research reveals an exposed service belonging to another organization:

1. Do not attempt to access data or validate impact through exploitation.
2. Preserve only the minimum information necessary to document the observation.
3. Use the organization's published security contact or vulnerability-disclosure process.
4. Avoid publishing sensitive identifiers before remediation.

## Repository issues

Use GitHub issues for documentation errors, outdated filters, broken links, or unsafe examples in this repository.

Do not post credentials, private keys, personal data, access tokens, or sensitive third-party system details in public issues.
