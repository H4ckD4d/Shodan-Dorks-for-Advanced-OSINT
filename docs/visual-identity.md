# Visual Identity System

> **Project owner / original creator / primary maintainer: Chris Cruz | h4ckd4d**

## Purpose

This document defines the visual language for **Project h4ckd4d** and **Shodan Dorks for Advanced OSINT**, taking inspiration from the strongest themes of **rifleman.us**: digital protection, threat visibility, investigation, intelligence, family safety, and the idea of bringing hidden risk into the light.

The visual system should communicate **precision, vigilance, protection, intelligence, and technical credibility** without looking militarized, sensational, or like an official government brand.

## Core visual concept

### Protect

Use shield geometry, safe boundaries, layered perimeter lines, and a subtle protected-person or family motif.

### Detect

Use telemetry grids, network nodes, radar arcs, signal traces, graph relationships, observability markers, and evidence-style data structures.

### Defend

Use controlled geometric structure, resilient layers, segmented network patterns, and clear security boundaries.

## Recommended palette

The project should use a dark technical foundation with restrained high-contrast accents.

| Role | Suggested visual direction |
| --- | --- |
| Base | Near-black / deep graphite |
| Primary | Dark navy / midnight blue |
| Intelligence accent | Electric cyan |
| Investigation accent | Violet / ultraviolet |
| Protection accent | Cool blue |
| Alert accent | Amber used sparingly |
| Text | White / cool light gray |

Avoid large areas of bright red unless the context is a genuine warning state.

## Graphic language

Recommended elements:

- shield outlines;
- abstract human/child protection silhouette used respectfully;
- network and relationship graphs;
- DNS / ASN / certificate relationship motifs;
- radar sweeps and telemetry rings;
- terminal-like data fragments;
- layered perimeter geometry;
- map/grid abstractions without displaying real target locations;
- subtle binary/hex/packet-inspired texture;
- evidence timeline markers;
- clean intelligence-dashboard framing.

## Elements to avoid

To keep the GitHub project focused on cybersecurity and child protection, project visuals should avoid:

- weapons or weapon silhouettes;
- explosive imagery;
- tactical combat imagery;
- police, military, intelligence-agency, or government seals;
- imagery suggesting official authority or affiliation;
- identifiable images of real children;
- fear-based or graphic victim imagery;
- excessive skulls, masks, or stereotypical "hacker" clichés.
